# EasyGit v2.1.1

A new logo, and in-app updates now come from the public EasyGit repository on
GitHub. No other changes; fully compatible with v2.1.0.

## Changes

- New EasyGit logo and app icon.
- **Check for updates** now reads releases from
  [github.com/zemacedo99/easygit](https://github.com/zemacedo99/easygit/releases).
  Each update is still checked (size and SHA-256) before anything installs.

## Updating

- From v2.1.0 or older: install this version manually once (installer or
  portable below). In-app updates come from GitHub from then on.

## Requirements

- Node.js is not required to run the packaged app.
- Git must still be installed on the user's machine.
- The installer is unsigned, so Windows SmartScreen may show a warning on first launch.

## Files

- `EasyGit Setup 2.1.1.exe` — recommended installer
- `EasyGit-2.1.1-portable.exe` — portable version
- `SHA256SUMS.txt` — checksums for both files
- `update.json` — information used by the in-app updater
