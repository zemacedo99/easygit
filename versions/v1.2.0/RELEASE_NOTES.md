# EasyGit v1.2.0

Add a project straight from an online link. Fully backwards-compatible with
v1.1.0; the default flow is unchanged.

## Highlights

- **Add repository from link or SSH** — in **Auto-find Git repositories**, choose
  *Add repository from link or SSH*, paste an online project link
  (`https://…`, `git@…`, or `ssh://…`), pick where to save it, and EasyGit
  downloads the project to your computer and adds it to your list.
- EasyGit **suggests a folder name** from the link and lets you edit it.
- **Safe by design:** it never overwrites an existing folder, uses your existing
  Git/SSH/HTTPS sign-in, and **never asks for or stores passwords**. Friendly,
  plain-language messages explain what to do if a download fails.

## Requirements

- Node.js is not required to run the packaged app.
- Git must still be installed on the user's machine.
- The installer is unsigned, so Windows SmartScreen may show a warning on first launch.

## Files

- `EasyGit Setup 1.2.0.exe` — recommended installer
- `EasyGit-1.2.0-portable.exe` — portable version
