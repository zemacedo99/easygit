# EasyGit v1.0.0

First packaged Windows release.

## Highlights

- Simple default flow: On this computer ⇄ Online project
- Upload my changes with one clear action
- Download latest version from the online project
- Auto-find local Git repositories
- Smart commit message suggestions
- Advanced Git flow available in settings
- Windows installer and portable executable
- EasyGit app icon and branding

## Requirements

- Node.js is not required to run the packaged app.
- Git must still be installed on the user’s machine.
- The installer is unsigned, so Windows SmartScreen may show a warning on first launch.

## Files

- `EasyGit Setup 1.0.0.exe` — recommended installer
- `EasyGit-1.0.0-portable.exe` — portable version
